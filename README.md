## 它会替你做什么

你不需要按任何快捷键，也不需要记得锁屏。手表在你手腕上，它就是你的钥匙。

- **离开即锁** —— 手表超出设定范围并持续数秒，Mac 自动锁屏。
- **回来即亮** —— 回到工位，屏幕自动点亮，解锁交给系统自带的「使用 Apple Watch 解锁」。
- **状态随时可见** —— 菜单栏实时显示信号强度、当前判定，以及上次锁定的时间与原因（仅本次运行内有效）。
- **一键掌控** —— 点开菜单栏可立即锁定、临时暂停，或查看信号强度与阈值的对应关系。

## 全部功能

| | 功能 | 说明 |
| --- | --- | --- |
| 🔒 | **自动锁定** | 基于蓝牙信号强度判定距离，跨过「已离开」阈值并持续设定秒数后锁屏 |
| 💡 | **靠近唤醒** | 回到范围内点亮显示器，解锁由 macOS 原生能力完成 |
| 📊 | **信号与阈值可视化** | 同轴阈值带直观显示当前信号落在「在身边 / 边界 / 已离开」哪一段 |
| 🎯 | **距离校准向导** | 保持办公姿势 10 秒，按你的实际环境自动生成阈值，不用自己猜数字 |
| 🔁 | **误锁反馈与自动调参** | 标记误锁后自动放宽阈值，越用越贴合你的习惯 |
| 🔔 | **异常通知** | 蓝牙异常、信号长期丢失、权限缺失时主动告知，并给出处理指引 |
| ⚙️ | **锁屏方式可选** | 模拟 ⌃⌘Q（默认）、系统接口免授权（可选，私有 API）、仅关闭显示器、或自定义命令 |
| 🎥 | **会议 / 演示暂缓锁定**（可选，默认关闭） | 有应用阻止显示器睡眠时先不锁屏，结束后补锁；设有最长暂缓上限，到点必锁 |
| 🔁 | **手动解锁后重新布防**（可选，默认关闭） | 你用密码解锁、但手表仍在远处时，键鼠空闲一段时间后再锁一次 |
| 📍 | **信任场所** | 把家、办公室等网络保存为信任场所，连接时自动暂停自动锁定，离开后恢复；默认没有任何场所，保存后才生效 |
| 📱 | **辅助设备**（iPhone / AirPods 等） | 手表只是偶尔收不到信号、而你选的设备还在附近时，先不锁屏；只会推迟「信号丢失」引起的锁定，最多 2 分钟 |
| 🧾 | **锁定记录** | 每次实际锁定的时间 · 原因 · 信号强度都留一条，只存在本机，可在「诊断」页导出 CSV |
| 🌐 | **简中 / 英文界面** | 随系统语言切换，权限弹窗文案同步本地化；[帮助手册](docs/help.md) / [Help](docs/help.en.md) |
| 🔄 | **手动检查更新** | 点一下查询 GitHub 最新版本，有新版时跳转下载页，不自动安装 |
| 🔐 | **开机启动 / 睡眠联动** | 开机即守护，唤醒后给一段宽限期避免误判 |

## 隐私：我们什么都不知道

这一点对健康与安全类工具尤其重要，所以写在功能之前。

- **默认零网络请求** —— 全部计算在本机完成。唯一的例外是你在「设置 → 关于」手动点「检查更新」：向 GitHub 发一次请求读取最新版本号，不带任何本机信息，不自动下载或安装。可自行验证：`lsof -i -P | grep WatchLock`。
- **不接触你的密码** —— 默认不托管、不存储、不传输任何密码；解锁完全交给系统。
- **不采集使用数据** —— 没有埋点，没有分析，没有崩溃上报。
- **最小权限** —— 必需的只有蓝牙；辅助功能（默认锁屏方式需要）和通知按需授权，另有一项**可选**的定位服务，仅用于显示 Wi-Fi 名称和「按位置的信任场所」，拒绝也不影响其余功能（见下表）。
- **无 Dock 图标** —— 安静地待在菜单栏，不打扰你的工作流。

「托管密码自动输入」是一个可选的进阶能力，默认关闭且会明确标注风险，可完全不用。

## 快速上手

1. 打开应用，菜单栏出现状态图标（由 logo 提炼的「环形锁体 + 锁梁」，五态表示在身边 / 已离开 / 搜索中 / 已暂停 / 已关闭）。
2. 跟随引导授权蓝牙（默认还要授权辅助功能用于模拟 ⌃⌘Q），并在「设备」里绑定你的 Apple Watch。
3. 在系统设置中开启「使用 Apple Watch 解锁」。**未绑定手表时自动锁定不会生效**（菜单栏会提示），请务必先完成第 2 步的绑定。
4. （推荐）跑一次「校准 → 距离校准向导」，按你的坐姿生成专属阈值。

之后一切自动发生。

## 系统权限

| 权限 | 为什么需要 | 不授权会怎样 |
| --- | --- | --- |
| **蓝牙** | 扫描 Apple Watch 的广播并测量距离 | 扫描不到设备，核心功能不可用 |
| **辅助功能** | 以模拟 ⌃⌘Q 的方式锁屏（默认方式） | 锁定时会收到明确通知与指引；也可改用「系统接口（免授权）」或「仅关闭显示器」避开该权限 |
| **通知** | 锁定、蓝牙不可用、权限缺失等事件的提醒 | 不影响锁定本身，只是看不到提醒；可在设置中整体关闭 |
| **定位服务**（可选） | 授权后「信任场所」可以按位置信任（同一个地点换了网络也生效），也能显示 Wi-Fi 名称（macOS 把它归在定位服务下） | 网络场所照常按网关识别，只是不能按位置信任、看不到网络名。位置只在本机比对，不上传；只有你保存了位置场所才会定位 |

应用不会请求「输入监控」「屏幕录制」等无关权限。若发现它索要额外权限，请立即停用并反馈。

## 常见问题

**手表就在旁边，为什么还是锁屏了？**

先看菜单栏的实测信号值，以它为准。手表贴近 Mac 时约 -42 dBm，默认「已离开」阈值 -70 通常够用。若仍误锁，跑一次「距离校准向导」按你的实际环境生成阈值。

**需要 Apple Watch 上装配套 App 吗？**

不需要。应用直接读取手表已有的蓝牙广播，手表端零安装、零设置。

**会耗电吗？**

应用使用系统低功耗扫描，常驻内存占用很小；手表端无需做任何事，不额外耗电。

**支持哪些 Mac 与手表？**

需要蓝牙低功耗（BLE），macOS 14 及以上。Apple Watch 各代的广播行为略有差异，应用会自动适应；若发现识别不稳定，请在 GitHub Issues 附上「设置 → 诊断」导出的日志反馈给我们。

**锁屏为什么走「模拟 ⌃⌘Q」？**

macOS 没有开放给第三方的公开锁屏 API。默认用模拟系统快捷键，等效于手动锁屏；需要辅助功能授权。若不想授权，可在「设置 → 通用 → 锁定方式」选「系统接口（免授权）」，它调用系统自带「锁定屏幕」所用的内部接口。该接口未公开，系统升级后可能失效，届时应用会通知你回退到 ⌃⌘Q 或「仅关闭显示器」。也可直接用「仅关闭显示器」或自定义命令。

**数据安全吗？会不会上传我的位置？**

不会。应用平时不联网（仅你手动点「检查更新」时访问一次 GitHub），距离判定只有蓝牙「近 / 远」的相对值。唯一与定位相关的是**可选**的定位服务授权：授权后可读取 Wi-Fi 名称，也可以把当前位置保存为「信任场所」；只有保存了位置场所才会定位，位置只在本机与场所比对，不上传，拒绝授权也不影响其余功能。

## 获取方式

当前**仅通过 [GitHub Release](https://github.com/MaelWeb/WatchLock/releases) 分发，不发布到 App Store**，提供同时支持 Apple Silicon 与 Intel 的通用 DMG（macOS 14+），并附带 `.dmg.sha256` 校验文件。

下载 DMG，打开后将 `WatchLock.app` 拖入 `Applications`。当前包使用 ad-hoc 签名，**未做 Developer ID 签名或 Apple 公证**，macOS 可能阻止首次打开；确认下载来源并核对 SHA-256 后，按系统提示在「系统设置 → 隐私与安全性」选择「仍要打开」。受管理设备的安全策略可能禁止运行，升级后蓝牙或辅助功能权限可能需要重新授予。

想自己编译或参与开发，见 [DEVELOPMENT.md](./DEVELOPMENT.md)。

## 已知限制

- Apple 未开放第三方自动解锁 API，解锁依赖系统自带「使用 Apple Watch 解锁」，本应用负责靠近时唤醒屏幕。
- 「托管密码自动输入」为高风险可选能力，默认关闭，需辅助功能权限。
- 信任场所靠网关识别网络，可被同一网络里的设备伪造，是方便功能，不是安全防线。
- 辅助设备的效果取决于 iPhone / AirPods 当时的蓝牙广播状态（例如 iPhone 息屏后可能不再广播）。
- 金属屏蔽、USB-C 扩展坞干扰等环境因素会影响蓝牙信号，校准向导可缓解。

## 关于

**应用名**：WatchLock —— 以手表为钥匙，为 Mac 上锁。

**标识**：小写 `w` 的右笔向上绕成闭环，形似开启的锁梁；既是首字母，也是「锁」。
