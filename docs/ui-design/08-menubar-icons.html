菜单栏状态图标

从应用 logo 提炼：环形锁体 + 锁梁。锁梁开 / 合表达「手表在不在」，其余三态靠锁体内的小标记区分，「已关闭」整体变淡。纯单色模板图，系统自动适配浅色 / 深色菜单栏。

从 logo 到图标

→

（logo 里最醒目的圆环）
开启锁梁
（左腿断开 = 开锁）
闭合锁梁
（锁住）
  • 画布 18×18，锁体圆心 (9, 11.2)、半径 5.1；锁梁半径 3.7；所有笔画外沿落在 [0.7, 17.3] 内，不贴边不裁切
  • 线宽 1.8，圆头圆角，与 SF Symbols 常规字重一致
  • 取舍 logo 里的 w 连笔尾巴在 18pt 下会糊成一团，只保留「环 + 梁」
