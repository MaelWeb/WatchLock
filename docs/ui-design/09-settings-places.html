网络场所靠网关识别，不需要任何授权。授权定位服务后，可以把当前位置保存为信任场所，列表里也能显示 Wi-Fi 名称，并在「网关相同但换了 Wi-Fi 名称」时不再信任。位置只在本机比对，不上传。
重新打包安装后，系统可能要求重新授权；授权丢失时位置场所不会生效（按「不在场所内」处理），网络场所照常工作。
网络指纹和位置只在本机比对，不上传。网络指纹可以被同一网络里的设备伪造，位置也可能因定位误差飘出范围，所以这是方便功能，不是安全防线；离开该场所后会立即恢复自动锁定。
