# WatchLock 帮助手册

WatchLock 是 macOS 菜单栏应用：戴着 Apple Watch 走开，Mac 自动锁屏；回到工位，自动点亮屏幕。解锁由系统自带的「使用 Apple Watch 解锁」完成。

## 1. 第一次使用

1. 打开应用，菜单栏出现图标，跟随引导走完。
2. 授权**蓝牙**（必需）。默认锁屏方式还需要**辅助功能**；不想授权可在「设置 → 通用 → 锁定方式」改用「系统接口（免授权）」或「仅关闭显示器」。
3. 在「设置 → 设备」里选择并绑定你的 Apple Watch。**未绑定手表时自动锁定不会生效**，菜单栏会提示。
4. 在 macOS「系统设置」里开启「使用 Apple Watch 解锁」，否则回来后只会亮屏，仍需手动输入密码。
5. （推荐）「设置 → 校准 → 距离校准向导」：保持日常坐姿 10 秒，生成适合你环境的阈值。

## 2. 菜单栏

| 图标状态 | 含义 |
| --- | --- |
| 在身边 | 手表信号强，保持解锁 |
| 已离开 | 手表离开并持续设定秒数，已（或即将）锁屏 |
| 搜索中 | 正在寻找手表信号 |
| 已暂停 | 你临时暂停了监控 |
| 已关闭 | 监控已关闭 |

面板里可以：立即锁定、临时暂停、查看实测信号值与阈值，以及点「刚才这次是误锁？」反馈误锁。

## 3. 设置

- **通用**：锁定方式、离开持续时间、开机启动、通知、两个可选例外（默认都关闭）：
  - 会议 / 演示暂缓锁定：有应用阻止显示器睡眠时先不锁，结束后补锁，设有最长暂缓上限。
  - 手动解锁后重新布防：用密码解锁但手表仍在远处时，键鼠空闲一段时间后再锁一次。
- **设备**：绑定 / 解除绑定手表。
- **校准**：距离校准向导；调整「在身边」「已离开」阈值。
- **诊断**：误锁统计与自动调参、诊断日志、广播抓包、调试开关。
- **关于**：版本、重新运行引导、检查更新、打开本手册。

## 4. 常见问题

**手表就在旁边，为什么还是锁屏了？**
先看菜单栏的实测信号值。手表贴近时约 -42 dBm，默认「已离开」阈值 -70 dBm 通常够用。仍误锁就跑一次距离校准向导，或在菜单栏标记误锁让应用自动放宽阈值。

**走开了但没锁屏？**
依次检查：已绑定手表；蓝牙已授权；锁定方式为「⌃⌘Q」时辅助功能已授权（缺失时会有通知）；没有开启「会议 / 演示暂缓锁定」且恰有应用在阻止显示器睡眠；监控未被暂停。「设置 → 诊断」的日志会写明每次没有锁定的原因。

**回来后只亮屏、不自动解锁？**
自动解锁由 macOS 完成，不是本应用。请确认「系统设置」里已开启「使用 Apple Watch 解锁」，手表已解锁并戴在手腕上。

**升级后又要重新授权？**
应用未做 Developer ID 签名 / 公证，替换 App 后系统可能要求重新授予蓝牙或辅助功能，按提示重新勾选即可。

**会联网吗？**
默认不联网。唯一的网络请求发生在你点击「关于 → 检查更新」时：向 GitHub 发送一次查询最新版本号的请求，不带任何本机信息，不自动下载或安装。

## 5. 更新

在「设置 → 关于」点「检查更新」。有新版本时会出现「前往下载」，在 GitHub Releases 页面下载 DMG，拖入「应用程序」覆盖即可。

## 6. 反馈问题

在 [GitHub Issues](https://github.com/MaelWeb/WatchLock/issues) 提交，并附上「设置 → 诊断」里导出的日志（日志已脱敏）。
